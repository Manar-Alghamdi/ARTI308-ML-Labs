Lab 10

Overview

This lab demonstrates how to build and evaluate a Support Vector Machine (SVM) classifier using the Iris dataset. The project includes data visualization, model training, prediction, evaluation, and hyperparameter tuning using GridSearchCV.

Dataset

The dataset used is the Iris dataset loaded from Seaborn.

Libraries Used

pandas
seaborn
matplotlib
scikit-learn

Tasks Performed

Loaded and explored the Iris dataset
Created visualizations using pairplot and KDE plot
Split the data into training and testing sets
Trained an SVM classifier using SVC
Evaluated the model using:
Confusion Matrix
Classification Report
Applied GridSearchCV to tune SVM parameters

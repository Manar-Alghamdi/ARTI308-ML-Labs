# Decision Trees and Random Forest Project

## Overview

This project applies machine learning models to a loan dataset to predict whether a borrower will fully pay the loan or not.

## Project Steps

- Import the required libraries

- Load and explore the loan dataset

- Perform exploratory data analysis using visualizations

- Convert categorical features into dummy variables

- Split the data into training and testing sets

- Train a Decision Tree classifier

- Train a Random Forest classifier

- Evaluate the models using classification report and confusion matrix

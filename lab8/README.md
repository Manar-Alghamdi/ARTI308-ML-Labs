In this lab, we applied the K-Nearest Neighbors (KNN) algorithm to classify data based on feature similarity.
 
⸻
 
⚙️ Steps Performed
Loaded and explored the dataset
Standardized the features using StandardScaler
Split the data into training and testing sets
Trained a KNN model with k=1
Evaluated the model using confusion matrix and classification report
Used the elbow method to find the best K value
Retrained the model using the optimal K
 
⸻
 
📈 Results
The model performance improved after selecting a better K value, achieving higher accuracy and more balanced precision and recall.

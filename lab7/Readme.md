Description

This Lab applies Logistic Regression to the Advertising Dataset in order to predict whether a user will click on an advertisement based on their features such as age, income, and internet usage.

⸻

📊 Dataset

The dataset contains information about users, including:
 • Daily Time Spent on Site
 • Age
 • Area Income
 • Daily Internet Usage
 • Gender (Male)
 • Clicked on Ad (Target variable)

⸻

⚙️ Steps Performed
 1. Imported necessary libraries (Pandas, NumPy, Matplotlib, Seaborn)
 2. Loaded and explored the dataset using info() and describe()
 3. Performed Exploratory Data Analysis (EDA) using visualizations (histogram, jointplots, pairplot)
 4. Selected relevant features for the model
 5. Split the data into training and testing sets
 6. Trained a Logistic Regression model
 7. Evaluated the model using classification report

⸻

📈 Results

The model achieved high accuracy (around 90%+), indicating strong performance in predicting whether a user will click on an advertisement. The precision, recall, and F1-score values show a balanced and reliable model
